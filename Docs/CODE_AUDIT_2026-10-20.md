## 已处理的问题

1. **好友通知重复生产**：真实通知对 10/11、12/13、14/15 的发送者、标题、正文、标签、图标和响应 URL 相同，只有原生通知 ID 不同。两个 Steam 根页面运行相同通知管理器，WebKit 把重复的 `ClientNotifications.DisplayClientNotification` 又提交到了客户端。现仅在桥接处停止这条重复生产请求；保留 `Notifications.RegisterForNotifications` 的原始通知回调、页面渲染和点击处理，不使用时间窗口或正文去重。新增现有桥接夹具中的回归用例，本次按要求未运行。
2. **恢复渲染设置时丢失备份**：`SteamWebHost+Energy` 在页面接受恢复请求之前就删除原值。现等页面回答 `ok` 后才删除，页面重载/不可用时保留备份。
3. **注册表清理失败后不再重试**：`ConfigRegistry.reconcile` 原来不论删除是否成功都丢弃记录。现保留失败项，使后续 reconcile 能再次删除旧覆盖值。
4. **发布重试引用旧步骤名**：`Tools/ci/publish.py` 仍要求已经不存在的合并测试/构建步骤。现对齐拆分后的步骤名，并分别校验已测试构建与明确跳过测试的构建。
